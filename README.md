# qaravan-forms

Публичная витрина форм обратной связи QARAVAN. Здесь живёт только код формы — вся остальная автоматика в приватном репозитории `qaravannyc/events-robot`.

## Почему отдельный публичный репозиторий

Vercel на плане Hobby не деплоит приватные репозитории организации (для этого нужен Pro). Поэтому папка `form/` вынесена сюда, в публичный репозиторий, а робот, выгрузки Partiful и рабочие заметки остались приватными.

## Маршруты

- `/<monday-item-id>` — форма отзыва для гостя
- `/<monday-item-id>/lead` — форма для волонтёра-ведущего
- `/feedback/<monday-item-id>` и `/feedback/<monday-item-id>/lead` — те же формы, старый вид ссылки
- `/survey` — исследование потребностей сообщества 2026 (папка `survey/`, отправка через `api/survey.mjs`)
- `/letter` — анкета на письмо поддержки для иммиграционного дела (папка `letter/`, приём через `api/letter.mjs`)
- `/event-volunteers` — запись волонтёров событий на роли организаторов по месяцам (папка `event-volunteers/`, приём через `/api/event-volunteers`). Это не общая запись волонтёров — та живёт на qaravan.org/volunteer
- `/support/gina` и `/support/simon` — анкеты групп поддержки: группа поддержки с Джиной и группа равной поддержки с Саймоном (папка `support/`, приём через `/api/support-groups`)
- `/support/send?t=…` — страница, с которой ведущая группы поддержки отправляет участникам ссылку на встречу (приём через `/api/meetings`; ссылку на страницу присылает письмо накануне встречи)

ID в ссылке — это id строки события на доске Event Calendar в monday.

## Опрос потребностей 2026 (`/survey`)

Анонимный опрос из 24 вопросов на шести языках — русский, английский,
украинский, грузинский, узбекский (латиница), казахский; выбор языка —
выпадающим списком в шапке, язык заполнения пишется в колонку Language. Ответы
ложатся на приватную доску monday
**Community Needs Survey 2026** (id `18426996689`): черновики автосохраняются в
группу In progress после каждого ответа, отправленные ответы переезжают в
Submitted. Один респондент — одна строка; браузер держит случайный response id
в localStorage, поэтому человек может прерваться и продолжить на том же
устройстве, а по личной ссылке `/survey?r=<response-id>` («Продолжить на другом
устройстве» внизу каждого раздела) — и на любом другом: GET `/api/survey?rid=`
отдаёт черновик с доски. Имён, почт и телефонов форма не собирает.

На версиях, переведённых с помощью ИИ (все, кроме русской и английской), внизу
каждого раздела есть тихая кнопка «Заметили ошибку в переводе?» — репорты
уходят на доску **Survey Translation Reports** (id `18427148568`): язык версии,
раздел и текст замечания, статус New → Fixed/Dismissed. Репорты анонимны и не
связаны с ответами на опрос. Структура данных и коды — в `survey/CODEBOOK.md`.

### Аналитика опроса

`tools/aggregate-survey.mjs` читает JSON из «⚙️ Raw answers» (источник истины —
машинные коды, а не переименовываемые метки), применяет правила баз (роутинговые
пропуски вне базы, «предпочитаю не отвечать» отдельной строкой, эксклюзивные
варианты вне числителей, подгруппы с базой < 10 подавляются) и переписывает
доску **Survey 2026 — Aggregates** (id `18427179045`): одна строка = один
столбик одного вывода, вкладки-представления по каждому анализу, журнал
прогонов в группе Run log. Группу A7 (темы открытых ответов, кодируются руками)
скрипт не трогает. Дашборд **QARAVAN Needs Survey 2026** (id `38957850`)
совмещает живые виджеты по доске ответов и посчитанные проценты с агрегатов.

Запуск: еженедельно по понедельникам Vercel-кроном через `/api/aggregate` —
для этого в переменных окружения Vercel должен быть задан `CRON_SECRET`
(без него эндпоинт отказывает). Вручную: `MONDAY_TOKEN=… node
tools/aggregate-survey.mjs` или GET `/api/aggregate?key=<CRON_SECRET>`.

## Анкета на письмо поддержки (`/letter`)

Форма для участников сообщества, которым нужно письмо-декларация от QARAVAN
для иммиграционного дела: `feedback.qaravan.org/letter`. 19 вопросов в четырёх
разделах (по решению команды форма не спрашивает A-number, не просит личную
историю / personal statement и не собирает документы; вместо даты рождения —
возраст; последний вопрос — открытый «Что-то ещё?» до 1000 знаков), по одному вопросу на экран, шесть языков (по умолчанию английский;
переключатель — в шапке). Дизайн и тексты — из прототипа Claude Design
«Letter Intake Form» (папка `letter/`, спецификация — в описании коммита и в
комментариях к файлам).

- `letter/index.html` + `letter/app.js` — сама анкета (без фреймворков).
  Тексты всех шести языков — `letter/strings.js`; названия событий —
  `letter/intake-events.js` (английский источник, идентификаторы позиционные,
  **не переставлять**) и `letter/events-i18n.js` (переводы по id); страны —
  `letter/countries.js` (ISO-коды, имена локализует браузер); невидимые синонимы
  для поиска по событиям («хайк» → hike/поход, «пати» → party) —
  `letter/search-synonyms.js`, группы слов-основ, дописывать можно свободно.
- `api/letter.mjs` — автосохранение после каждого ответа (`mode: draft`),
  отправка (`submit`), выдача черновика по личной ссылке (`GET ?rid=`) и
  сообщения об ошибках перевода (`mode: feedback`). Всё в одной функции: на плане
  Hobby Vercel не собирает деплой больше чем с 12 функциями в `api/`. Общий код и
  карта колонок — `lib/letter-board.mjs`, письма — `lib/letter-mail.mjs`.
- Ответы ложатся на приватную доску monday **Letters of Support — Immigration
  Cases** (id `18429448469`): черновики — в группу «Form — started, not
  finished» (Form status = In progress), отправленные — в «Form — answers
  received» (Letter Status = Answers received) плюс апдейт с полным читаемым
  текстом ответов. Колонок немного: Form status и Form progress (на каком
  вопросе, сколько минут, язык), Age, Proceeding, Identities & experiences, Roles at QARAVAN,
  Attorney email, Key events at home, Other support letters, References at
  QARAVAN, Partner, Consents given, Anything else, Translation feedback (что
  написали в «Заметили ошибку в переводе?» внизу любого шага); всё про
  участие (частота, первый контакт, события, вклад) собирается в существующую
  Involvement Summary. Каждый ответ — одна строка; ключ — «⚙️ Intake id» (UUID,
  который придумывает браузер). «⚙️ Raw answers» — JSON для личной ссылки,
  «⚙️ Path log» — путь по анкете (шаги, время, направление: next / back / jump /
  peek / skip / error / submit…) — по нему видно, кто дошёл до последнего шага
  и где бросил.
- Личная ссылка `/letter?r=<intake id>` открывает тот же черновик на любом
  устройстве; она уходит письмом на почту сразу после шага «Как с вами
  связаться» (Gmail API, те же `GOOGLE_*`, что и для фото — в токене должен
  быть scope `gmail.send`; без него форма работает, а ссылку показывает на
  экране). После отправки — письмо-подтверждение.
- Локально: `node tools/letter-dev.mjs` — сервер на :3999 с поддельным monday
  (ничего никуда не пишет), удобно прокликать анкету целиком.

## Запись волонтёров событий (`/event-volunteers`)

Анкета «Стать волонтёром событий QARAVAN» — для команды, которая придумывает и ведёт события (не путать с общей записью волонтёров на qaravan.org/volunteer, куда пишутся все; анкета сама отсылает туда тех, кто хочет помогать иначе): `feedback.qaravan.org/event-volunteers`. Одна
страница, RU/EN: имя, местоимения, Telegram, Instagram, телефон и почта
(обязательны), шесть ролей карточками с описанием и часами, месяцы, как часто,
был(а) ли на событиях, комментарий. Черновик держится в localStorage до отправки.
Ссылка с `?role=maker` (или `?role=maker,keeper`) сразу отмечает роль — удобно
для постов «ищем Maker»; `?lang=en` открывает английскую версию.

- Месяцы продлеваются сами: анкета предлагает `MONTHS_AHEAD` (6) месяцев начиная
  со следующего. Метку нового месяца («Апрель 2027») на доске сервер создаёт сам
  при первой заявке (`create_labels_if_missing`). Представление «Команда: …» и
  график в «Сводке» для нового месяца на доске добавляются вручную.
- Приём — `lib/event-volunteers.mjs`. Своей функции нет (лимит 12 функций на Hobby):
  `vercel.json` переписывает `/api/event-volunteers` на `/api/survey?form=event-volunteers`,
  и `api/survey.mjs` первой строкой отдаёт такой запрос в `lib/event-volunteers.mjs`.
- Заявки ложатся на приватную доску monday **Волонтёры событий — запись на роли**
  (id `18432838181`), группа «Заявки»: одна заявка — одна строка со статусом
  «Новая», плюс апдейт с полным текстом ответов. Колонки и метки этой доски
  названы по-русски по просьбе команды — исключение из правила выше; метки в
  `lib/event-volunteers.mjs` должны совпадать с доской символ в символ. Уведомление
  о новой заявке и напоминания — автоматизации самой доски.
- Локально: `node tools/event-volunteers-dev.mjs` — сервер на :3998 с поддельным
  monday, `/__db` показывает, что ушло бы на доску. Проверки:
  `node --test tools/event-volunteers.test.mjs`.

## Анкеты групп поддержки (`/support/gina`, `/support/simon`)

Фирменные анкеты вместо старых: `feedback.qaravan.org/support/gina` заменяет
Typeform (dbH75jNe), `feedback.qaravan.org/support/simon` — форму monday на
доске Саймона. Вопросы те же, что были в старых формах; одна страница, RU/EN
(`?lang=en` открывает английскую), черновик держится в localStorage до отправки.
После отправки — «Спасибо» и кнопка в Telegram-сообщество RUSA Connects.

- `support/gina.html`, `support/simon.html` — у каждой свой `<head>` (заголовок и
  превью ссылки в Telegram), всё остальное общее: вопросы и тексты обеих анкет —
  `support/app.js` (`FORMS` и `TEXTS`), стили — `support/support.css`.
- Приём — `lib/support-groups.mjs`. Своей функции нет (лимит 12 функций на Hobby):
  `vercel.json` переписывает `/api/support-groups` на `/api/survey?form=support-groups`,
  и `api/survey.mjs` отдаёт такой запрос туда.
- Джина: приватная доска monday **Support Group with Gina — Sign-ups**
  (id `18433061986`), новые анкеты — в группу «New sign-ups» со статусом New.
  Ответы из Typeform за 2023–2026 (92, без тестовых) перенесены в группу
  «Typeform sign-ups, 2023–2026» той же доски, колонка Source = Typeform.
- Вопрос «Что вам сейчас нужнее всего?» (у Джины): до трёх вариантов в порядке
  выбора; «Другое» открывает поле «своими словами». Варианты и их порядок взяты из ответов на старый вопрос
  Typeform «три главные потребности»: 82 ответа людей, живущих в США (ответы из-за
  рубежа не считались), темы размечены вручную, сверху — самые частые. Видны первые
  восемь и «Другое», остальные — по кнопке «Показать ещё». Выбранное ложится в
  колонку Needs, своими словами — в «Needs — in their words». Выбранные варианты
  (здесь и в идентичностях у Саймона) загораются цветами бренда по очереди выбора:
  оранжевый, жёлтый (с чернильным краем), зелёный — по дизайн-системе заливкой с
  текстом бывают только они; красный, голубой и фиолетовый мелкий текст не несут. Коды и метки — `NEEDS` в
  `lib/support-groups.mjs`, порядок и тексты — `FORMS.gina` в `support/app.js`.
- Саймон: существующая доска **Группа равной поддержки с Саймоном: регистрация на
  участие** (id `5469799506`), группа «Website submissions…». Анкета пишет в те же
  колонки, что писала форма monday (их названия русские — доска старше правила
  выше, не переименовываем), поэтому автоматизация доски — письмо Эзре о новой
  регистрации — работает как раньше. Метки идентичностей и формата встреч в
  `lib/support-groups.mjs` должны совпадать с доской символ в символ.
- В «Как с вами связаться» у обеих анкет, кроме почты и телефона, — Telegram и
  Instagram по желанию; на обеих досках для них есть колонки Telegram и Instagram.
- Каждая анкета — одна строка плюс апдейт с полным текстом ответов.
- Перед письмом анкета смотрит, что о человеке уже есть в monday (`lib/person-lookup.mjs`,
  только чтение, пока создаётся строка): карточка на доске Attendees (по почте, по «Other
  emails», по телефону), мероприятия из календаря событий — «Confirmed attendees» и
  «Verified registrations» на прошедших неотменённых событиях, кроме «Did not attend /
  declined» (так же считает Attendance 2026), проведённые мероприятия, волонтёрство

  письмо уходит с пометкой, что проверить не получилось.

  тот же Gmail-токен, что у анкеты на письмо), свёрстанное по дизайн-системе 2026-09,
  как сами анкеты: разделы «Контакты», «Ответы», «Что нужнее всего» и кнопка
  «Открыть в monday». Кому — `NOTIFY` в том же файле (сейчас у Джины —

  переменные Vercel `SUPPORT_NOTIFY_GINA` и `SUPPORT_NOTIFY_SIMON` (адреса через запятую)

  анкета Саймона приходит Эзре дважды; старую форму monday на этой доске закрыли.
- Локально: `node tools/support-groups-dev.mjs` — сервер на :3997 с поддельным

## Письмо со ссылкой на встречу (`/support/send`)

Джина и Саймон рассылают ссылку на встречу одной кнопкой и без входа в monday
(`lib/meetings.mjs`, `support/send.html`, `support/send.js`).

- **Накануне.** Каждый день около полудня по Нью-Йорку Vercel-крон зовёт
  `/api/meeting-prompts` (`vercel.json`, 16:00 UTC; на плане Hobby — в течение
  этого часа). Для каждой встречи на завтра в календаре событий (строка, в названии
  которой есть Gina / Simon; «Cancelled» пропускается) ведущей приходит письмо от
  info@qaravan.org с кнопкой «Проверить и отправить». Спрашиваем один раз на встречу
  (отметка `prompted` в «⚙️ Meeting email»). Адреса ведущих — `GROUPS` в
  `lib/meetings.mjs` (gina@rusalgbtq.org, simon@rusalgbtq.org), переопределяются
  `MEETINGS_LEADER_GINA` / `MEETINGS_LEADER_SIMON`.
- **Страница.** Кнопка открывает `/support/send?t=<ключ>`: ссылка на встречу и
  телефон (по умолчанию — с прошлой отправки, а в самый первый раз — постоянные из
  `GROUPS`), тема, текст (по умолчанию — прошлый текст ведущей; у Джины первый — по
  её письму от 23 сентября 2026), предпросмотр «Как увидят участники», список людей
  с доски группы с галочками (один человек — одна почта), поиск, «Добавить человека».
  Правки держатся в localStorage до отправки.
- **Отправка.** Одно письмо: ведущей в «Кому», всем выбранным — в скрытой копии, ответы
  — ведущей. Галочки ложатся на доску группы и подставляются к следующей встрече: у
  Джины галочка — это статус «Joined» (отметили — «Joined», сняли — «Not now»; новые
  анкеты приходят со статусом «New», без галочки), у Саймона — колонка «Gets meeting
  emails». Добавленные вручную — новыми строками (у Джины — «Joined» и Source «Added
  by hand»). На строке встречи в календаре остаются «Meeting link», «⚙️ Meeting email»
  (текст, ссылка, когда и скольким) и апдейт без адресов участников.
- **Ключ** в ссылке — HMAC от строки встречи, группы и срока (до 6 часов после начала);
  секрет — `MEETINGS_SECRET` или, если его нет, производный от `MONDAY_TOKEN`. По ссылке
  видны адреса участников, поэтому её получает только ведущая.
- **Вручную** (нужен `CRON_SECRET` в Vercel): `/api/meeting-prompts?key=<CRON_SECRET>&item=<id
  строки>` — письмо ведущей по этой встрече прямо сейчас; `&to=<почта>` вместе с `item` — то
  же письмо с настоящей кнопкой на другой адрес, для проверки (встреча не помечается);
  `&dry=1` — показать, что ушло бы, со ссылками. Без `CRON_SECRET` обычный ежедневный прогон
  всё равно работает.
- Локально: `node tools/meetings-dev.mjs` — сервер на :3996 с примерными людьми и поддельной
  почтой, печатает ссылку на страницу; `/__mail` — что ушло бы. Проверки:
  `node --test tools/meetings.test.mjs`.

## Дизайн

Все формы (отзыв гостя и ведущего, несколько событий, фото, опрос, анкета на
письмо, анкеты групп поддержки) и страницы после ссылок из писем (отписка, «меня там не было») собраны
по дизайн-системе QARAVAN, ревизия 2026-09: Fira Sans для текста и Fira Sans
Condensed для заголовков, кнопок и подписей; белая страница, квадратные формы,
шесть цветов бренда только флажками и метками, без тонированных подложек.

- `assets/qaravan.css` — шрифты, токены (значения из `tokens.json` дизайн-системы)
  и базовые правила. Подключается первым на каждой странице.
- `assets/forms.css` — общие компоненты форм отзыва и опроса: переключатель
  RU/EN, звёзды, варианты ответа, поля, кнопки, сообщения об ошибке, блок
  доната, загрузка фото. В `<style>` страниц остаётся только своё.
- `assets/fonts/` — файлы шрифтов из дизайн-системы (кириллица, украинский,
  казахский, узбекский; грузинский — FiraGO), лицензия OFL рядом.
- `assets/logo-wordmark.svg` — логотип: официальные контуры, не живой шрифт.

Анкета `/letter` берёт только `qaravan.css`: у неё свои компоненты в
`letter/index.html`.

## Переменные окружения (задаются в Vercel, не в коде)

- `MONDAY_TOKEN` — обязательна, без неё форма не найдёт событие
- `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `GOOGLE_REFRESH_TOKEN` — загрузка фото и видео в Google Photos и письма анкеты `/letter` (scope `gmail.send`)
- `FORM_BASE` — необязательна, адрес формы для ссылок в письмах анкеты (по умолчанию `https://feedback.qaravan.org`)

## Правило

В этот репозиторий никогда не коммитятся токены и ключи, он публичный.

## Feedback photo uploads

The attendee, lead, photos-only, and multi-event forms accept up to 50 files per
event. The server applies the same limit. Four direct Google Photos transfers
can run at once; a separate worker prepares one image at a time so selection
and form controls stay responsive.

JPEG optimization preserves the full pixel dimensions and uses quality 0.94.
It replaces a file only when at least 10% smaller. The original-files checkbox
applies to subsequent selections and skips re-encoding. Other formats and
videos remain unchanged, and unsupported browsers fall back to the original.
Optimized JPEGs lose camera metadata such as EXIF capture dates; use originals
when that metadata or an untouched publication source is needed.

Run the upload, cancellation, 50-file, and album-failure regression checks with:

```sh
node --test tools/photo-*.test.mjs
```

Feedback copy follows [NN/G error-message guidance](https://www.nngroup.com/articles/error-message-guidelines/)
and the [GOV.UK button guidance](https://design-system.service.gov.uk/components/button/):
name the action, describe the current state, and give a concrete recovery step.
Failed selected files require retry or removal before submission. Album failures
show a warning even when an attempted backup succeeds.
