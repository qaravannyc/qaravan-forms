# qaravan-forms

Публичная витрина форм обратной связи QARAVAN. Здесь живёт только код формы — вся остальная автоматика в приватном репозитории `qaravannyc/events-robot`.

## Почему отдельный публичный репозиторий

Vercel на плане Hobby не деплоит приватные репозитории организации (для этого нужен Pro). Поэтому папка `form/` вынесена сюда, в публичный репозиторий, а робот, выгрузки Partiful и рабочие заметки остались приватными.

## Маршруты

- `/<monday-item-id>` — форма отзыва для гостя
- `/<monday-item-id>/lead` — форма для волонтёра-ведущего
- `/feedback/<monday-item-id>` и `/feedback/<monday-item-id>/lead` — те же формы, старый вид ссылки

ID в ссылке — это id строки события на доске Event Calendar в monday.

## Переменные окружения (задаются в Vercel, не в коде)

- `MONDAY_TOKEN` — обязательна, без неё форма не найдёт событие
- `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `GOOGLE_REFRESH_TOKEN` — нужны только для загрузки фото и видео в Google Photos

## Правило

В этот репозиторий никогда не коммитятся токены и ключи, он публичный.
